# typed-endpoint

Typed-endpoint связывает типизированную декларацию HTTP endpoint с двумя
потребителями: runtime backend и OpenAPI 3.1. Декларация остаётся единственным
источником для path/query/body, ответов, ошибок декодирования и security.

Начните с [Быстрый старт и DTO](quickstart.md). Границы ядра и адаптеров описаны в
[Архитектура](architecture.md), а эксплуатационные ограничения — в
[Эксплуатация и ограничения](production.md). Оценка поддержки стандарта приведена в
[Покрытие OpenAPI 3.1](openapi_coverage.md). Для постепенного переноса старого
Opium-приложения есть отдельное [руководство по миграции](opium_migration.md).

Генерация DTO и сервера из OpenAPI 3.0.3/3.2.1 с общими типами для нескольких групп описана в
[OpenAPI-first руководстве](openapi_first.md). Архитектура генератора и выбор
версии экспорта 3.0.3/3.1.0/3.2.1 зафиксированы в
[ADR 0002](adr/0002-openapi-first-codegen.md), дальнейшие направления — в
[плане развития](roadmap.md).
