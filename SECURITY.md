# Политика безопасности

## Сообщение об уязвимости

Не публикуйте сведения о ещё не исправленной уязвимости в обычном issue.
Используйте приватный GitHub Security Advisory репозитория
`prekel/typed-endpoint` и приложите:

- затронутую версию или commit;
- минимальный пример воспроизведения;
- ожидаемое и фактическое поведение;
- оценку влияния и известные способы обхода.

Подтверждение получения и сроки исправления зависят от доступности maintainer;
заранее гарантированный SLA пока не заявляется. Публикация advisory и credit
согласуются после подготовки исправления.

## Границы ответственности

Typed-endpoint проверяет объявленные HTTP inputs, ограничивает буферизацию body,
не отражает rejected values в стандартных decode errors и запрещает CR/LF в
типизированных response headers. Приложение по-прежнему отвечает за TLS,
authentication policy, secrets, CORS, rate limiting, timeout, reverse-proxy
trust, generic exception boundary и своевременное обновление HTTP framework.

Поддерживаемой считается только последняя опубликованная версия каждого
пакета. До первого релиза API и security fixes находятся в ветке разработки.
